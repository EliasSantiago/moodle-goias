# Changelog

## 1.1.0 (2026-11-11)

- Adopts the Design System Goiás (Expresso UI kit): Poppins typeface, Expresso greys,
  government green, the Expresso type scale and semantic tokens per colour scheme.
- Components restyled after the design system: pill buttons with brand halo, fields,
  labels and validation messages, cards with 1px border and 24px radius, menus, modals,
  alerts, tags, underlined tabs, tables, paginator, progress bar and avatars.
- Navbar with the LogoMark (monogram, site name and organisation); primary navigation,
  course index and drawers styled as the app shell sidebar.
- Login page in the AuthLayout: government bar, back to home link, colour scheme
  selector and a centred card with the brand panel.
- New high contrast scheme; the navbar toggle is now a menu (light, dark, high contrast,
  follow the device).
- New settings: organisation, government bar and portal link.
- The brand colour default changes from graphite to the government green (#15967d).
  Sites still on the old default are moved automatically on upgrade.

## 1.0.0 (2026-11-11)

- First release for Moodle 5.2.
- Graphite palette, Plus Jakarta Sans typeface, rounded cards and translucent navbar.
- Light and dark colour schemes with a navbar toggle (saved per user, follows the device by default).
- Configurable accent colour, logo, compact logo and login panel title/text.
- Split-screen login with a gradient panel.
